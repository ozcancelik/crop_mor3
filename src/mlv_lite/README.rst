Raw video v1.1 (MLV Lite)
=========================

Records 10, 12 or 14-bit RAW video, uncompressed or lossless (LJ92).

Crop Mor3 build: records the 1:1 crop, 1x3 tall anamorphic and
3x3 High-FPS modes of Crop Mor3 (crop_rec), writes RAWC binning
metadata so 1x3 clips desqueeze automatically, and draws framing
guides that match the recorded area.

Based on the original RAW recording module updated to MLV file format
(credits: dmilligan), without the extra features from mlv_rec.

You may want to load mlv_play for reviewing clips.
